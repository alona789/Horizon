## [数字 vs 实体游戏：所有权才是核心问题](https://popcar.bearblog.dev/its-about-ownership/) ⭐️ 8.0/10

一篇博客文章指出，实体游戏与数字游戏之争忽略了关键问题：由于限制性许可协议和 DRM，消费者实际上并不真正拥有他们购买的数字游戏。 这很重要，因为它凸显了游戏行业乃至更广泛领域中日益严重的消费者权利问题——公司可以撤销对已购买内容的访问权限。这可能会推动对更强所有权保护和监管的需求。 文章指出，Steam 不施加硬性 DRM，因此用户可以在没有启动器的情况下离线游玩，但许多其他平台使用限制性 DRM，如果服务器关闭，游戏可能无法运行。作者呼吁法律承认数字所有权，包括可转让性和永久访问权。

hackernews · popcar2 · 7月5日 14:56 · [社区讨论](https://news.ycombinator.com/item?id=48794750)

**背景**: 数字版权管理（DRM）是指限制数字内容使用方式的访问控制技术，通常禁止复制或共享。软件许可是一种法律框架，消费者购买的是使用软件的许可，而非软件本身的所有权。这种区别意味着公司可以撤销访问权限或施加限制，而实体所有权则无法做到这一点。

## [更好的模型：更差的工具](https://simonwillison.net/2026/Jul/4/better-models-worse-tools/#atom-everything) ⭐️ 8.0/10

Armin Ronacher 报告称，较新的 Claude 模型（Opus 4.8 和 Sonnet 5）在遵循工具调用模式方面比旧模型更差，尤其是在 Pi 的编辑工具中虚构嵌套的 edits 数组中的额外字段。 这种退化令人惊讶，因为较新的模型本应有所改进，并且表明针对特定工具（例如 Claude Code 的编辑工具）的训练可能会降低自定义第三方工具模式的性能，从而影响 Pi 等编码工具的可靠性。 该问题仅出现在较新的 Anthropic 模型（Opus 4.8 和 Sonnet 5）中，它们会发明模式中不存在的键，导致 Pi 拒绝工具调用并要求重试，尽管编辑内容通常是正确的。

rss · Simon Willison · 7月4日 22:53

**背景**: 工具调用模式定义了 LLM 调用外部工具时函数参数的预期 JSON 格式。像 Claude 这样的模型通过强化学习训练来使用特定工具，例如 Claude Code 的内置文本编辑器。然而，这种训练会产生偏差，导致模型偏离其他自定义模式，从而增加错误。

## [能力门：通过内部置信信号控制工具使用](https://www.reddit.com/r/MachineLearning/comments/1unw5un/competence_gate_gating_tooluse_on_a_small_models/) ⭐️ 8.0/10

作者发布了一个 10MB 的 LoRA 适配器，用于 Qwen3.5-4B 模型，该适配器基于模型的内部置信信号控制工具使用，提升了错误检测能力并减少了私有查询泄露。 该方法通过利用内部激活解决了小语言模型的一个关键局限——即口头化置信度差，从而使其在工具使用和隐私敏感应用中更加可靠。 该门控机制将错误检测的 d′提高了 0.46（95% CI [0.01, 0.89]），并将发送到公共搜索的私有查询从 22%减少到 10%（减少 0.12，95% CI [0.02, 0.22]）。它还提供了带有引用和置信带的可追溯答案。

reddit · r/MachineLearning · /u/Synthium- · 7月5日 07:49

**背景**: 小语言模型通常难以准确表达自身的置信度，倾向于高估。最近的研究表明，可以从模型激活中提取内部置信信号并用于驱动行为。能力门适配器读取这些内部信号，以决定何时直接回答或调用外部工具，从而在不依赖更大模型的情况下提高可靠性。

## [USAF：在低显存 GPU 上对 MoE 模型进行稀疏微调](https://www.reddit.com/r/MachineLearning/comments/1unl62q/if_your_gpu_can_run_inference_it_should_be_able/) ⭐️ 8.0/10

一种名为 USAF 的新开源方法允许在仅 12 GB 显存的 GPU 上对混合专家（MoE）模型进行稀疏微调，已在 AMD RX 6750 XT 上对 Qwen3-30B-A3B 进行了演示。 USAF 消除了对高端 GPU 的需求，使研究人员和从业者能够更广泛地访问模型定制，从而普及了大型 MoE 模型的微调。 USAF 通过仅训练稀疏专家权重和路由器来工作，避免了完整的适配器训练；它以 Apache 2.0 许可证发布，无商业意图。

reddit · r/MachineLearning · /u/tsuyu122 · 7月4日 21:56

**背景**: 混合专家（MoE）模型使用多个专门的子网络（专家）和一个路由器来为每个输入选择激活哪些专家，从而在较低推理成本下实现更大的模型规模。由于密集的参数更新，微调这类模型通常需要大量 GPU 内存。像 USAF 这样的稀疏微调方法通过仅更新一部分参数来减少内存使用。
